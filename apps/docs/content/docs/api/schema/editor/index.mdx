| [addLimitIssue](functions/addLimitIssue.md) | Add a stable `EDITOR_LIMIT_EXCEEDED` issue when `actual` exceeds the frozen limit for `limitKey`. Shared by every collection schema (DD-0019 §7.3: limits produce stable validation errors; data is never silently truncated). |
| [canonicalizeAppearance](functions/canonicalizeAppearance.md) | - |
| [canonicalSerializeAuthoring](functions/canonicalSerializeAuthoring.md) | Canonically serialize an authoring state and measure its UTF-8 byte length. Deterministic: permuted key insertion orders produce identical bytes. |
| [canonicalSerializeFragment](functions/canonicalSerializeFragment.md) | Canonically serialize an arbitrary JSON-safe fragment (component definitions, rich-text values, commands) for per-entity byte limits. Same rules, no compaction step. |
| [compactAuthoringState](functions/compactAuthoringState.md) | Compact a full authoring state (pure; unknown keys preserved at every level; ids and order untouched). |
| [compactNodeRecord](functions/compactNodeRecord.md) | Compact one node record. Returns `undefined` when nothing but the `version` marker (and no unknown keys) remains — invariant 3 says such records must not exist. |
| [compactResponsiveValue](functions/compactResponsiveValue.md) | Compact one `ResponsiveValue`: remove `undefined` base, remove `null` override entries (write-time removal signal), remove override values that compact to empty objects, and collapse to `undefined` when neither base nor overrides remain. |
| [createAuthoringMigrationRegistry](functions/createAuthoringMigrationRegistry.md) | Create an empty migration registry (v1: no steps registered). |
| [createEmptyAuthoringState](functions/createEmptyAuthoringState.md) | An empty, canonical v1 authoring state. |
| [detectAuthoringVersion](functions/detectAuthoringVersion.md) | Classify a candidate sidecar value without deep parsing. Never throws. |
| [limitedRecordSchema](functions/limitedRecordSchema.md) | Build a record schema whose size is capped by a frozen §7.3 limit and whose keys are validated as identifiers. |
| [normalizeAuthoringState](functions/normalizeAuthoringState.md) | Canonical normalization: compaction plus breakpoint display-order normalization (widest first). The result is the shape all writers must persist (invariant 10). |
| [normalizeBreakpointOrder](functions/normalizeBreakpointOrder.md) | Recompute display `order` from widths, widest first (DD-0019 §12.2: order is normalized from widths, not authored). Pure; returns a new array, input untouched. |
| [responsiveValueSchema](functions/responsiveValueSchema.md) | Build a `ResponsiveValue<T>` schema around a value schema (DD-0019 §9.1). Override entries admit `null` on parse — `null` clears the local override and resumes inheritance; compaction removes it and canonical state never persists it. |
| [safeParseAppearance](functions/safeParseAppearance.md) | - |
| [safeParseAuthoringEnvelope](functions/safeParseAuthoringEnvelope.md) | Safe-parse the shallow envelope.
