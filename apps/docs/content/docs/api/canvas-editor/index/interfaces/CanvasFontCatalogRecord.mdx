An entry as a catalog stores it: the authoring shape plus the tier it was
created at. Stamped by [createFontCatalog](../functions/createFontCatalog) so authors never repeat it
per entry, and preserved by [mergeCatalogs](../functions/mergeCatalogs) so merging a merged
catalog still resolves each family at its true precedence.
