Build a [CanvasEditorActions](CanvasEditorActions.md) facade over a studio context. For
non-React callers and tests; components should prefer
[useCanvasActions](../functions/useCanvasActions). The context's `getIR`/stores are read at call
time, so the facade stays correct across edits as long as `ctx` itself is
the live context object.
