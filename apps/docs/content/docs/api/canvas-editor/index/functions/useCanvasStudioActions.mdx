[CanvasStudioActions](../interfaces/CanvasStudioActions) as a hook — the `export`-augmented sibling of
[useCanvasActions](useCanvasActions.md). Unlike `useCanvasActions` (which only reads the
STABLE store handles so it never re-renders on commit), this hook also
reads the full reactive `useCanvasStudio()` context because `export()`
needs the live `stage`/`brandKit` at call time.
