Defined in: [packages/capabilities/canvas/editor/src/panels/fields.tsx:496](https://github.com/ancyloce/anvilkit-studio/blob/main/src/panels/fields.tsx#L496)

Returns a stable [CommitPatch](../type-aliases/CommitPatch) bound to the current studio context.
Identical to the inspector's former local `commitPatch` — every field
mutation flows through `ctx.commit({ type: "node.update", … })`. Discrete
controls (switches, selects, buttons) keep using this; continuous fields
upgrade to the `contract` prop (§10, B-12).
