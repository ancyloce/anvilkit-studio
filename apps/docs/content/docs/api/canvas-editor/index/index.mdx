## Classes

| Class | Description |
| ------ | ------ |
| [CanvasErrorBoundary](classes/CanvasErrorBoundary.md) | Error boundary for the canvas editor (W10). Without it, any render-time throw — a malformed IR, a missing asset, or a bug in a host-supplied panel — unwinds the whole React tree and the user loses the entire editor. Wrapping the panel registry and the stage subtree contains a failure to that region: the rest of the editor keeps working and the user gets a recover affordance instead of a blank screen. Exported so hosts can wrap their own custom panels too. |
| [CanvasExportCancelledError](classes/CanvasExportCancelledError.md) | Thrown by a multi-page built-in exporter (PDF) when [CanvasExportRequest.isCancelled](interfaces/CanvasExportRequest.md#iscancelled) starts returning `true` between page iterations (FR-154). The export dialog's `runExport` catches this specifically and marks the export `"cancelled"` instead of `"failed"`, discarding the artifact instead of downloading it. A host-injected multi-page exporter honoring `isCancelled` may throw the same class to get identical cancel semantics. |
| [CanvasExportEmptyError](classes/CanvasExportEmptyError.md) | Thrown when a requested export scope resolves to nothing exportable — an empty selection, or a `"pages"` request whose ids no longer exist on the document. Callers map it to their own "Nothing to export" surface (the dialog's `export-store` fail phase; the headless `export()` action's rejected promise). |
