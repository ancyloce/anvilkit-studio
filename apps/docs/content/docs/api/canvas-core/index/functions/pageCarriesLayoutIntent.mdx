Defined in: [ir/invariants.ts:174](https://github.com/ancyloce/anvilkit-studio/blob/main/src/ir/invariants.ts#L174)

Does any node on this page carry layout intent (see
[nodeCarriesLayoutIntent](nodeCarriesLayoutIntent.md))? One `walkPage` pass; used by consumers
that need to know whether stored geometry alone can be trusted for a page —
e.g. the SVG serializer deciding whether to warn `LAYOUT_UNRESOLVED`.
