Drop shadow as an entry in the extensible effect list (C-03, PRD 0012
§9.4/FR-077). Supersedes the legacy per-node `shadow` field — see
[resolveNodeEffects](../functions/resolveNodeEffects) for the documented precedence — and adds
`spread` over [CanvasShadow](CanvasShadow.md).
