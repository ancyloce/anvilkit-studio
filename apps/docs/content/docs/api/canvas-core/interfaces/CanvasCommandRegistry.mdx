### register()

Defined in: [extensions/command-registry.ts:44](https://github.com/ancyloce/anvilkit-studio/blob/main/src/extensions/command-registry.ts#L44)

Register an extension command handler. A built-in command type is
unshadowable, and a type may only be registered once — mirroring
[CanvasNodeKindRegistry.register](CanvasNodeKindRegistry.md#register)'s guard (C-13).

#### Type Parameters

| Type Parameter | Default type |

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `handler` | [`CanvasCommandHandler`](CanvasCommandHandler.md)\&lt;`C`, `Inverse`\&gt; |

#### Returns

`void`

#### Throws

CanvasExtensionError with code `"builtin-command-shadowed"` when
`handler.type` names a built-in command, or `"duplicate-command"` when
another extension already registered it.
