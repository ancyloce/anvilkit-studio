### register()

```ts

```

Defined in: [extensions/node-kind-registry.ts:92](https://github.com/ancyloce/anvilkit-studio/blob/main/src/extensions/node-kind-registry.ts#L92)

Register an extension kind. Seeded built-in kinds are unshadowable, a
kind may only be registered once, and (P0-5) a container kind is rejected
outright — see [CanvasNodeKindDefinition.isContainer](CanvasNodeKindDefinition.md#iscontainer).

#### Parameters

| `def` | [`CanvasNodeKindDefinition`](CanvasNodeKindDefinition.md)\&lt;`N`\&gt; |

#### Returns

`void`

#### Throws

CanvasExtensionError with code `"builtin-kind-shadowed"` when the
kind is a seeded built-in, `"duplicate-kind"` when another extension
already registered it, or `"container-kind-unsupported"` when
`def.isContainer` is true.
