Sort key components, in the §16.2 order: page, then tree position, then
instance, property, code.

`pageOrder`/`nodeOrder` are supplied by the scan rather than derived here, so
ordering reflects document order rather than lexicographic id order — two
pages named "b" and "a" must still report in document sequence.
