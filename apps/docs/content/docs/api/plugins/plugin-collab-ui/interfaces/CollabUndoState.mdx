Local undo/redo state snapshot (§4.1.2). Returned by
[useCollabUndoState](../functions/useCollabUndoState). `undo`/`redo` are stable callbacks bound
to the active adapter; `canUndo`/`canRedo` drive toolbar
enabled-state.
