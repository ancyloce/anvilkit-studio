## 实时预览

<ComponentPreview name="Columns" />

A Puck-native repeatable multi-column layout with an independent slot in each
column.

```tsx
import { Columns, componentConfig } from "@anvilkit/columns";

export function Example() {
  return (
    <Columns
      columns={[
        { label: "One", content: <p>First</p> },
        { label: "Two", content: <p>Second</p> },
      ]}
    />
  );
}

export const puckComponent = componentConfig;
```

Authors can manage two to four columns and choose the collapse breakpoint,
gap, and alignment. The repeated column elements share a stable `column`
authoring target.

## 属性参考

派生自该组件的 Puck `fields` 模式。

| 字段 | 类型 | 默认值 |
|-------|------|---------|
| `appearance` | custom | — |
| `interactions` | custom | — |
| `bindings` | custom | — |
| `columns` | array | `[{"label":"Column 1","content":[]},{"label":"Column 2","c…` |
| `gap` | select ("none" \| "sm" \| "md" \| "lg") | `"md"` |
| `collapseAt` | select ("never" \| "sm" \| "md" \| "lg") | `"md"` |
| `alignment` | radio ("stretch" \| "start" \| "center" \| "end") | `"stretch"` |
| `animation` | object | — |
| `classNames` | object | — |

## 默认属性

```json
{
  "columns": [
    {

    {

    }

  "collapseAt": "md",
  "alignment": "stretch"
}
```
